# Habit Quest

A gamified daily habit tracker and to-do list built with HTML, CSS, and React (via CDN). No installs, no frameworks, no build steps. Just open `index.html` in your browser and start tracking.

**Live demo:** [fatima4038.github.io/habit-quest](https://fatima4038.github.io/habit-quest/)

---

## Features

- **Daily score** — see your day as a percentage based on tasks completed
- **XP system** — earn points based on task difficulty (Easy +10, Medium +20, Hard +35)
- **Rank progression** — climb from Novice all the way to Legend
- **Streak tracker** — stay consistent day after day
- **Custom tasks** — add your own to-dos with a category and difficulty level
- **Category filters** — view tasks by Deen, Health, Study, or Life
- **Persistent storage** — your tasks and XP are saved locally in your browser

---

## How to Use

**Option 1 — Open locally**
Download `index.html` and double-click it. Opens in any browser, no setup needed.

**Option 2 — Live on GitHub Pages**
Visit the live link above — nothing to install.

## Built With

- React 18 (via CDN — no npm needed)
- Babel Standalone (JSX in the browser)
- Vanilla CSS
- localStorage for persistence
